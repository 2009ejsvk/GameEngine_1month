## 1. 프로그램의 시작: main.cpp 이해하기

게임 엔진이 어떻게 시작되는지 알아봅시다.

### main.cpp의 흐름

```cpp
int APIENTRY wWinMain(...)
{
    // 1. 엔진 초기화
    CEngine::GetInst()->Init(hInstance, TEXT("GameClient"), ...);

    // 2. CDO(Class Default Object) 등록
    CEngine::CreateCDO<CPlayer>();
    CEngine::CreateCDO<CBullet>();

    // 3. 시작 월드 생성
    CWorldManager::GetInst()->CreateWorld<CMainWorld>(false);

    // 4. 게임 실행
    int Ret = CEngine::GetInst()->Run();

    // 5. 종료
    CEngine::DestroyInst();

    return Ret;
}
```

### 각 단계 설명

1. **엔진 초기화**: DirectX 초기화, 윈도우 생성, 해상도 설정 (1280x720)
2. **CDO 등록**: 게임 오브젝트의 "청사진"을 미리 등록 (나중에 복사해서 사용)
3. **월드 생성**: 게임이 실행될 "공간" 생성
4. **게임 실행**: 메인 루프 시작 (Update → Render 반복)
5. **종료**: 메모리 정리

**핵심 개념**: 게임 엔진은 "초기화 → 루프 → 종료"의 구조입니다.

## 2. GameObject란 무엇인가?

게임에 등장하는 모든 것(플레이어, 총알, 몬스터 등)의 기본 단위입니다.

### GameObject의 핵심 멤버 변수

`GameEngine/Object/GameObject.h` 파일을 보면:

```cpp
class CGameObject
{
protected:
    std::string  mName;                    // 오브젝트 이름
    bool         mEnable = true;           // 활성화 여부
    bool         mAlive = true;            // 살아있는지 (false면 삭제됨)

    // 컴포넌트들을 담는 리스트
    std::vector<std::shared_ptr<CSceneComponent>>  mSceneComponentList;
    std::vector<std::shared_ptr<CObjectComponent>> mObjectComponentList;

    std::weak_ptr<CSceneComponent> mRoot;  // 루트 컴포넌트 (Transform 역할)
    std::weak_ptr<CWorld>          mWorld; // 어느 월드에 속해있는지
};
```

### GameObject의 생명주기

```
생성 → Init() → Begin() → Update() → PostUpdate() → Render() → Destroy()
                          ↑__________________|
                          (매 프레임 반복)
```

- **Init()**: 컴포넌트 생성, 초기 설정
- **Begin()**: 월드에 배치된 직후 1번만 호출
- **Update()**: 매 프레임 실행 (이동, AI 등)
- **PostUpdate()**: Update 이후 처리
- **Render()**: 화면에 그리기
- **Destroy()**: 삭제 시 정리 작업

**비유**: GameObject는 빈 "상자"입니다. 여기에 기능(컴포넌트)을 담아서 완성합니다.

## 3. Component 시스템

컴포넌트는 GameObject에 붙여서 기능을 추가하는 "부품"입니다.

### 컴포넌트의 종류

```cpp
enum class EComponentType
{
    Scene,   // 위치/회전/크기 정보가 있는 컴포넌트 (MeshComponent, ColliderBox2D 등)
    Object   // 위치 정보가 없는 컴포넌트 (ProjectileMovementComponent, StateComponent 등)
};
```

### 주요 컴포넌트들

| 컴포넌트 이름 | 타입 | 역할 |
|------------|------|------|
| `CMeshComponent` | Scene | 화면에 그림을 그림 |
| `CColliderBox2D` | Scene | 2D 박스 충돌 처리 |
| `CAnimation2DComponent` | Scene | 2D 애니메이션 재생 |
| `CProjectileMovementComponent` | Object | 발사체 움직임 (총알, 미사일) |
| `CObjectMovementComponent` | Object | 일반 오브젝트 움직임 |
| `CStateComponent` | Object | 체력(HP) 관리 |

### 컴포넌트 생성 예제

```cpp
bool CBullet::Init()
{
    // 1. 메시 컴포넌트 생성 (그림 그리기)
    mMeshComponent = CreateComponent<CMeshComponent>("Mesh");

    auto Mesh = mMeshComponent.lock();
    Mesh->SetShader("MaterialColor2D");      // 셰이더 설정
    Mesh->SetMesh("CenterRectColor");        // 사각형 메시
    Mesh->SetRelativeScale(50.f, 50.f);      // 크기 50x50

    // 2. 움직임 컴포넌트 생성
    mMovement = CreateComponent<CProjectileMovementComponent>("Movement");

    auto Movement = mMovement.lock();
    Movement->SetSpeed(300.f);               // 속도 설정
    Movement->SetRange(600.f);               // 사거리 설정
    Movement->SetMoveDir(GetAxis(EAxis::Y)); // 위쪽으로 이동

    // 3. 충돌 컴포넌트 생성
    mBody = CreateComponent<CColliderBox2D>("Body");

    auto Body = mBody.lock();
    Body->SetCollisionProfile("PlayerAttack");  // 충돌 프로필 설정
    Body->SetBoxSize(100.f, 100.f);             // 충돌 박스 크기

    return true;
}
```

**핵심**: 레고 블록처럼 필요한 컴포넌트를 조립해서 GameObject를 완성합니다!

## 4. Transform: 위치, 회전, 크기

모든 SceneComponent는 위치, 회전, 크기 정보를 가집니다.

### Relative vs World

```cpp
// Relative: 부모 기준의 상대적 위치/회전/크기
SetRelativePos(100.f, 200.f);      // 부모로부터 (100, 200) 떨어진 위치
SetRelativeScale(2.f, 2.f);        // 부모 크기의 2배

// World: 월드 기준의 절대적 위치/회전/크기
SetWorldPos(500.f, 300.f);         // 화면의 절대 좌표 (500, 300)
SetWorldScale(50.f, 50.f);         // 절대 크기 50x50
```

### 부모-자식 관계

```
Player (Root)
  ├─ Gun (Child1)  - Player를 따라다님
  └─ Shield (Child2) - Player를 따라다님
```

자식 컴포넌트는 부모를 자동으로 따라다닙니다!

### 자주 사용하는 함수들

```cpp
// 위치 설정
SetRelativePos(x, y);      // 상대 위치 설정
AddRelativePos(x, y);      // 상대 위치에 더하기
SetWorldPos(x, y);         // 절대 위치 설정
AddWorldPos(x, y);         // 절대 위치에 더하기

// 크기 설정
SetRelativeScale(x, y);    // 상대 크기 설정
SetWorldScale(x, y);       // 절대 크기 설정

// 회전 설정
SetRelativeRotationZ(angle); // Z축 회전 (2D에서 주로 사용)
AddRelativeRotationZ(angle); // Z축 회전 누적
```

**실습 예제**:
```cpp
// 총알을 플레이어 앞에 생성
auto Bullet = mWorld->CreateGameObject<CBullet>("Bullet");
Bullet->SetWorldPos(GetWorldPos());           // 플레이어 위치에서 시작
Bullet->SetMoveDir(GetAxis(EAxis::Y));        // 위쪽으로 발사
```

## 5. 렌더링 기초

화면에 그림을 그리는 방법을 알아봅시다.

### 렌더링에 필요한 3요소

1. **Mesh**: 어떤 모양을 그릴 것인가? (사각형, 원 등)
2. **Shader**: 어떻게 그릴 것인가? (색상, 텍스처 등)
3. **Material**: 어떤 속성으로 그릴 것인가? (색깔, 투명도 등)

### 기본 렌더링 설정

```cpp
auto Mesh = CreateComponent<CMeshComponent>("Mesh");

// 1. 셰이더 설정 (그리는 방법)
Mesh->SetShader("MaterialColor2D");  // 단색으로 그리기
// 또는
Mesh->SetShader("Texture2D");        // 텍스처(이미지)로 그리기

// 2. 메시 설정 (모양)
Mesh->SetMesh("CenterRectColor");    // 중심점이 가운데인 사각형
Mesh->SetMesh("RectColor");          // 중심점이 왼쪽 아래인 사각형

// 3. 크기 설정
Mesh->SetRelativeScale(100.f, 100.f); // 100x100 크기

// 4. 색상 설정 (단색 셰이더일 경우)
Mesh->SetMaterialBaseColor(0, 1.f, 0.f, 0.f, 1.f); // 빨간색 (R, G, B, A)

// 5. 텍스처 설정 (텍스처 셰이더일 경우)
Mesh->AddTexture(0, "PlayerTexture", TEXT("Player.png"));
```

### 렌더 레이어 (그리는 순서)

```cpp
Mesh->SetRenderLayer(0);  // 낮은 숫자 = 먼저 그림 (뒤에 배치)
Mesh->SetRenderLayer(10); // 높은 숫자 = 나중에 그림 (앞에 배치)
```

**예시**:
- 배경: Layer 0
- 플레이어: Layer 5
- UI: Layer 10

## 6. 충돌 시스템

오브젝트들이 서로 부딪히는 것을 감지하는 시스템입니다.

### 충돌 컴포넌트 생성

```cpp
// 1. Collider 컴포넌트 생성
mBody = CreateComponent<CColliderBox2D>("Body");
auto Body = mBody.lock();

// 2. 충돌 박스 크기 설정
Body->SetBoxSize(100.f, 100.f);

// 3. 충돌 프로필 설정 (누구와 충돌할지 결정)
Body->SetCollisionProfile("PlayerAttack");  // 플레이어 공격
// 또는
Body->SetCollisionProfile("Monster");       // 몬스터
Body->SetCollisionProfile("Player");        // 플레이어

// 4. 디버그 그리기 (충돌 박스를 눈으로 확인)
Body->SetDebugDraw(true);

// 5. 충돌 콜백 함수 등록
Body->SetCollisionBeginFunction<CBullet>(this, &CBullet::CollisionBegin);
Body->SetCollisionEndFunction<CBullet>(this, &CBullet::CollisionEnd);
```

### 충돌 프로필 종류

| 프로필 이름 | 설명 |
|----------|------|
| `Player` | 플레이어 몸 |
| `Monster` | 몬스터 몸 |
| `PlayerAttack` | 플레이어가 쏜 총알/공격 |
| `MonsterAttack` | 몬스터가 쏜 총알/공격 |

### 충돌 처리 함수

```cpp
// 충돌이 시작될 때 호출
void CBullet::CollisionBegin(const FVector3& HitPoint, CCollider* Dest)
{
    // 총알이 무언가와 부딪혔을 때
    Destroy();  // 총알 삭제
}

// 충돌이 끝날 때 호출
void CBullet::CollisionEnd(CCollider* Dest)
{
    // 충돌이 끝났을 때 처리
}
```

**동작 원리**:
1. 매 프레임마다 모든 Collider의 위치/크기를 확인
2. 서로 겹치는지 검사
3. 겹치면 `CollisionBegin` 호출
4. 떨어지면 `CollisionEnd` 호출

## 7. 실전 예제: Bullet 클래스 분석

실제 게임에서 사용되는 총알 클래스를 분석해봅시다.

### Bullet 클래스 구조

`Client/Player/Bullet.h`와 `Bullet.cpp`를 보면:

```cpp
class CBullet : public CGameObject
{
private:
    // 컴포넌트들
    std::weak_ptr<CMeshComponent>              mMeshComponent;  // 그림
    std::weak_ptr<CProjectileMovementComponent> mMovement;      // 움직임
    std::weak_ptr<CColliderBox2D>              mBody;           // 충돌

    // 설정값들
    float    mDistance = 600.f;  // 사거리
    float    mSpeed = 300.f;     // 속도
    FVector3 mMoveDir;           // 이동 방향
};
```

### Init() 함수 상세 분석

```cpp
bool CBullet::Init()
{
    CGameObject::Init();  // 부모 클래스 초기화

    // [1단계] 메시 컴포넌트 생성 - 화면에 그림 그리기
    mMeshComponent = CreateComponent<CMeshComponent>("Mesh");
    auto Mesh = mMeshComponent.lock();

    if (Mesh)
    {
        Mesh->SetShader("MaterialColor2D");      // 단색 셰이더
        Mesh->SetMesh("CenterRectColor");        // 중심 사각형 메시
        Mesh->SetRelativeScale(50.f, 50.f);      // 50x50 크기
    }

    // [2단계] 움직임 컴포넌트 생성 - 발사체처럼 움직이기
    mMovement = CreateComponent<CProjectileMovementComponent>("Movement");
    auto Movement = mMovement.lock();

    if (Movement)
    {
        Movement->SetMoveDir(GetAxis(EAxis::Y));  // 위쪽으로 발사
        Movement->SetRange(600.f);                // 600 거리만큼 날아감
        Movement->SetSpeed(300.f);                // 속도 300
        Movement->SetUpdateComponent(mMeshComponent); // 메시를 움직임

        // 사거리 도달 시 호출될 함수 등록
        Movement->SetRangeFunction<CBullet>(this, &CBullet::MoveEndFunction);
    }

    // [3단계] 충돌 컴포넌트 생성 - 충돌 감지
    mBody = CreateComponent<CColliderBox2D>("Body");
    auto Body = mBody.lock();

    if (Body)
    {
        Body->SetCollisionProfile("PlayerAttack");  // 플레이어 공격으로 설정
        Body->SetBoxSize(100.f, 100.f);             // 충돌 박스 크기
        Body->SetDebugDraw(true);                   // 디버그 표시

        // 충돌 콜백 함수 등록
        Body->SetCollisionBeginFunction<CBullet>(this, &CBullet::CollisionBegin);
        Body->SetCollisionEndFunction<CBullet>(this, &CBullet::CollisionEnd);
    }

    return true;
}
```

### 충돌 처리

```cpp
// 충돌이 시작될 때 (무언가와 부딪혔을 때)
void CBullet::CollisionBegin(const FVector3& HitPoint, CCollider* Dest)
{
    Destroy();  // 총알 삭제
}

// 사거리에 도달했을 때
void CBullet::MoveEndFunction()
{
    Destroy();  // 총알 삭제
}
```

### Bullet이 하는 일 요약

1. **생성**: 플레이어가 공격 버튼을 누르면 생성
2. **초기화**: `Init()`에서 메시, 움직임, 충돌 컴포넌트 생성
3. **이동**: `ProjectileMovementComponent`가 자동으로 움직임
4. **충돌 검사**: 매 프레임마다 충돌 확인
5. **삭제**: 충돌하거나 사거리 도달 시 `Destroy()` 호출

## 8. 직접 만들어보기

이제 여러분이 직접 만들어볼 차례입니다!

### 초급 과제: 간단한 장애물 만들기

**목표**: 화면에 움직이지 않는 빨간 사각형 장애물 만들기

```cpp
// Client/Object/Obstacle.h
#pragma once
#include "Object/GameObject.h"

class CObstacle : public CGameObject
{
protected:
    CObstacle();
    virtual ~CObstacle();

private:
    std::weak_ptr<class CMeshComponent> mMesh;

public:
    virtual bool Init();

protected:
    virtual CObstacle* Clone();
};
```

```cpp
// Client/Object/Obstacle.cpp
#include "Obstacle.h"
#include "Component/MeshComponent.h"

CObstacle::CObstacle()
{
    SetClassType<CObstacle>();
}

CObstacle::~CObstacle()
{
}

bool CObstacle::Init()
{
    CGameObject::Init();

    // 메시 컴포넌트 생성
    mMesh = CreateComponent<CMeshComponent>("Mesh");
    auto Mesh = mMesh.lock();

    if (Mesh)
    {
        Mesh->SetShader("MaterialColor2D");
        Mesh->SetMesh("CenterRectColor");
        Mesh->SetRelativeScale(100.f, 100.f);
        Mesh->SetMaterialBaseColor(0, 1.f, 0.f, 0.f, 1.f); // 빨간색
    }

    return true;
}

CObstacle* CObstacle::Clone()
{
    return new CObstacle(*this);
}
```

### 중급 과제: 움직이는 적 만들기

**힌트**:
1. `CObstacle`을 복사해서 `CEnemy.h/cpp` 만들기
2. `Update()` 함수에서 `AddWorldPos()`로 이동시키기
3. 좌우로 왕복하도록 만들기

```cpp
void CEnemy::Update(float DeltaTime)
{
    CGameObject::Update(DeltaTime);

    // 왼쪽으로 이동
    AddWorldPos(-100.f * DeltaTime, 0.f);

    // 화면 밖으로 나가면 오른쪽으로 순간이동
    if (GetWorldPos().x < 0.f)
        SetWorldPos(1280.f, GetWorldPos().y);
}
```

### 고급 과제: 플레이어 따라다니는 적 만들기

**힌트**:
1. `Update()`에서 플레이어 위치 찾기
2. 플레이어 방향 계산
3. 그 방향으로 이동

```cpp
void CEnemy::Update(float DeltaTime)
{
    CGameObject::Update(DeltaTime);

    // 플레이어 찾기
    auto World = mWorld.lock();
    if (World)
    {
        auto Player = World->FindObject<CPlayer>("Player");
        auto PlayerPtr = Player.lock();

        if (PlayerPtr)
        {
            // 플레이어 방향 계산
            FVector3 Dir = PlayerPtr->GetWorldPos() - GetWorldPos();
            Dir.Normalize();  // 방향 벡터로 변환

            // 그 방향으로 이동
            AddWorldPos(Dir * 150.f * DeltaTime);
        }
    }
}
```

## 유용한 팁

### 디버깅 팁

1. **충돌 박스 보기**: `SetDebugDraw(true)`
2. **위치 확인**: `GetWorldPos()`로 현재 위치 확인
3. **콘솔 출력**: `OutputDebugString()` 사용

### 자주 하는 실수

1. **weak_ptr을 lock() 안 함**
   ```cpp
   // ❌ 잘못된 방법
   mMeshComponent->SetShader("Texture2D");

   // ✅ 올바른 방법
   auto Mesh = mMeshComponent.lock();
   if (Mesh)
       Mesh->SetShader("Texture2D");
   ```

2. **CDO 등록 안 함**
   ```cpp
   // main.cpp에서 꼭 등록하세요!
   CEngine::CreateCDO<CMyNewObject>();
   ```

3. **Init()에서 부모 Init() 안 부름**
   ```cpp
   bool CMyObject::Init()
   {
       CGameObject::Init();  // 꼭 호출!
       // ...
   }
   ```
