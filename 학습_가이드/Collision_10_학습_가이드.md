  10. 학습 가이드

  10-1. 코드를 따라 칠 때 순서

  1단계: 데이터 구조 (EngineInfo.h)
     → enum, struct 타입 정의

  2단계: CollisionInfoManager
     → 싱글톤 패턴 이해
     → 채널과 프로파일 관리

  3단계: Collider 기본 클래스
     → 추상 클래스 설계
     → 콜백 함수 패턴

  4단계: ColliderBox2D 구체 클래스
     → 상속 구조 이해
     → AABB 계산 로직

  5단계: Collision 알고리즘
     → AABB 충돌 (간단)
     → OBB 충돌 (분리축 정리)
     → Sphere 충돌
     → Box-Sphere 충돌

  6단계: WorldCollision
     → 이중 루프 구조
     → 충돌 상태 관리

  7단계: 사용 예제
     → 실제 게임 오브젝트 적용

  10-2. 핵심 개념 정리

  // ============================================
  // 1. 충돌 채널(Channel)
  // ============================================
  // - 오브젝트를 카테고리로 분류
  // - 예: Player, Monster, Item, Projectile
  // - 언리얼 엔진과 동일한 개념

  // ============================================
  // 2. 충돌 프로파일(Profile)
  // ============================================
  // - 특정 채널의 충돌 규칙 정의
  // - Interaction 배열로 다른 채널과의 관계 설정
  // - 예: Player는 Monster와 충돌, Player끼리는 무시

  // ============================================
  // 3. AABB (Axis-Aligned Bounding Box)
  // ============================================
  // - 축에 정렬된 바운딩 박스
  // - 회전 없을 때 사용
  // - 매우 빠름 (단순 좌표 비교)

  // ============================================
  // 4. OBB (Oriented Bounding Box)
  // ============================================
  // - 회전된 바운딩 박스
  // - 분리축 정리(SAT) 사용
  // - AABB보다 느림

  // ============================================
  // 5. 분리축 정리 (Separating Axis Theorem)
  // ============================================
  // - 두 볼록 도형이 분리되어 있으면
  //   그들을 분리하는 축이 존재한다
  // - 모든 후보 축에서 투영이 겹치면 충돌

  // ============================================
  // 6. 충돌 이벤트
  // ============================================
  // - CollisionBegin: 충돌 시작 (Enter)
  // - 계속 충돌: 매 프레임 충돌 중 (Stay)
  // - CollisionEnd: 충돌 종료 (Exit)
