# Teamster Mode Switch Semantics

운영 모드 전환과 진행 중 화물은 같은 것으로 취급하지 않는다.

- 모드 전환은 건물의 이후 생산, 입력 요구, 방문 소비 의미를 즉시 바꾼다.
- 이미 팀스터가 적재한 화물은 `CargoType` 그대로 유지되며 목적지까지 기존 exact 자원으로 도착한다.
- 아직 적재되지 않고 예약만 된 물량은 `RequestedType` 예약 상태로 남아 있으며, source에 해당 exact 재고가 남아 있을 때만 픽업된다.
- source에 예약한 exact 재고가 더 이상 없으면 해당 픽업은 실패하고, 팀스터는 사무소 복귀 또는 재계획 경로를 탄다.

금지할 설명:

- "모드 전환 후 화물이 자동으로 새 품목으로 치환된다."
- "이동 중이던 설탕이 담배로 바뀐다."

권장 설명:

- "모드 전환은 이후 생산과 새 배송 계획에 반영된다."
- "이미 실린 화물은 기존 품목으로 도착하고, 예약만 된 물량만 남은 exact 재고 기준으로 다시 픽업된다."
